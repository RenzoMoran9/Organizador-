# Norte — Organizador de Vida Personal

Herramienta para organizar todos los ámbitos de tu vida diaria (trabajo, familia, horarios, hábitos) y vencer la procrastinación con un sistema simple: **capturar → organizar → ejecutar**.

📋 El plan completo del proyecto está en [PLAN.md](./PLAN.md):

- El problema que resuelve y cómo ataca la procrastinación
- Áreas de vida y módulos (Vista "Hoy", agenda con time-blocking, hábitos, Modo Enfoque, revisión semanal)
- Principios de diseño (intuitivo, profesional, modo oscuro, responsive)
- Arquitectura técnica propuesta (React + Vite + Tailwind, PWA, datos locales primero)
- Hoja de ruta por fases, empezando por un MVP usable desde el día uno
